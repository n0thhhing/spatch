Install

Get Spatch on your phone

Spatch Manager does the work: it patches Spotify on your phone, signs it with a key made there and installs it. You need the exact Spotify version Spatch is built for.

info

Supported build: Spotify for Android 9.1.98.521 (version code 148115007), as an APKM bundle. Spatch checks the file's SHA-256 and refuses anything else.

Install Spatch Manager

Download spatch-manager.apk from the latest release and open it. Android asks once to allow installs from your browser. Android 10 or newer.

Get the Spotify APKM

Download Spotify 9.1.98.521 as an APKM from APKMirror, which only publishes uploads signed with Spotify's real key. On the download page use the plain Download APK Bundle button; the big coloured ones are ads. If that exact Spotify version is already installed unmodified, you can skip this step.

Choose the APKM

In the manager tap Choose Spotify APKM and pick the file from Downloads. The manager keeps a copy, so you never pick it again.

Make room

A Spotify signed by Spotify can't be updated by a differently signed app, so the manager asks to uninstall it first; this removes downloaded songs. Then turn off Play Store auto-update for Spotify so Play doesn't offer an update that would fail.

Install Spatch

Tap Install Spatch. The manager downloads the newest patches, checks every file, signs and installs. Open Spotify and sign in.

Back up your key

On the Signing key card tap Export and keep the .p12 file and its password somewhere safe. With it a new phone can keep updating the same install.

warning

Spatch is unofficial and changes Spotify's app, which is against Spotify's terms of use. It only changes how the app looks, but use it at your own risk.

update

Updating

Tell me about new patches notifies you twice a day at most. Tap the notification and the manager updates straight away; on Android 12+ it skips the confirmation screen once it installed Spotify.

sync_alt

Already patched on a computer?

Import the keystore you signed with (Signing key, Import) and the manager installs over it as an update, keeping your data. Choose the APKM once, since a patched install has no original left in it.

developer_mode

Developer build

Flip Developer build in the manager and tap Switch build to get Developer options: self tests, a frame monitor, a touch inspector and logs. Settings stay.

terminal

Prefer a computer?

The patcher is a Rust command-line tool. See below.

Patching on a computer

Requires Rust, Java and Android build-tools (aapt2, zipalign, apksigner), plus your own signing key.

cargo build --release
./target/release/spatch inspect <input.apkm>
./target/release/spatch patch <input.apkm> --out <dir> --theme gruvbox \
    --keystore <file> --alias <name> --ks-pass-env SPATCH_KS_PASS
adb install-multiple -r base.apk split_config.*.apk

Add --debug for Developer options. spatch bundle writes a patch bundle for the manager instead of a signed set.

Troubleshooting

"Spotify is signed with a different key"

The installed Spotify wasn't signed by your manager's key. Import the key it was signed with, or uninstall it (this removes downloads) and install again.

"That file isn't the Spotify APKM Spatch is made for"

The file is a different version or was modified. Download 9.1.98.521 again from APKMirror and pick the APKM, not an APK or XAPK.

The quick update didn't take

Tap Install again: the manager falls back to reinstalling every APK.

Couldn't reach GitHub

The manager needs a connection to find and download patches. Check your network and tap Check for updates.
