Get Spatch on your phone.

Spatch Manager patches Spotify on your phone, signs it with a key made there, and installs it. You need Android 10 or newer and the exact Spotify version Spatch is built for.

Android 10 or newer Spotify 9.2.0.2053 Version code 148387875 APKM bundle
Download Manager About the Manager Patch on a computer

Supported build. Spotify for Android 9.2.0.2053 (version code 148387875) as an APKM bundle. Spatch Manager checks the file's SHA-256 and refuses anything else.

  1. Install Spatch Manager

    Download spatch-manager.apk from the latest release and open it. Android asks once to allow installs from your browser. Requires Android 10 or newer.

  2. Get the Spotify APKM

    Get Spotify 9.2.0.2053 (version code 148387875) as an APKM, an unmodified build signed with Spotify's real key; the Manager checks it and refuses anything else. With an invite to a Spatch source, skip this: the Manager downloads the right file for you. Skip it too if that exact Spotify version is already installed unmodified.

  3. Choose the APKM

    In the Manager tap Choose Spotify APKM and pick the file from Downloads. The Manager keeps a copy, so you never pick it again.

  4. Make room

    A Spotify signed by Spotify cannot be updated by a differently signed app, so the Manager asks to uninstall it first. This removes downloaded songs. Turn off Play Store auto-update for Spotify so Play does not offer an update that would fail.

  5. Install Spatch

    Tap Install Spatch. The Manager downloads the newest patches, checks every file, signs the build, and installs it. Open Spotify and sign in.

  6. Back up your key

    On the Signing key card tap Export and keep the .p12 file and its password somewhere safe. With it, a new phone can keep updating the same install.

Use at your own risk. Spatch is unofficial and changes Spotify's app, which is against Spotify's terms of use. It only changes how the app looks, but use it at your own risk.

Updates, keys, and settings.

Every piece of the player is a setting once you are in. Open Spotify's side panel and choose Spatch, or use the calmer player top bar's more menu.

  • UpdatingTurn on Tell me about new patches and the Manager notifies you twice a day at most. Tap the notification to update straight away; on Android 12 or newer it skips the confirmation screen once it installed Spotify.
  • Patched on a computerOpen Signing key in the Manager and tap Import to load the keystore you signed with. The Manager installs over your existing build as an update and keeps your data. Choose the APKM once, since a patched install has no original left in it.
  • Developer buildFlip Developer build in the Manager and tap Switch build to unlock Developer options: self tests, a frame monitor, a touch inspector, and logs. Your settings stay.
  • Options to tryTurn on the optional two-line lyric strip in the player (configurable from one to three lines), opt into the landscape player, enable direct audio read (no microphone permission), or add home-screen widgets and the Quick Settings play/pause tile.

Patching on a computer.

The patcher is a Rust command-line tool. It needs Rust, Java, Android build-tools (aapt2, zipalign, apksigner), and your own signing key.

cargo build --release
./target/release/spatch inspect <input.apkm>
./target/release/spatch patch <input.apkm> --out <dir> --theme gruvbox \
    --keystore <file> --alias <name> --ks-pass-env SPATCH_KS_PASS
adb install-multiple -r base.apk split_config.*.apk

Add --debug for Developer options. spatch bundle writes a patch bundle for the Manager instead of a signed set.

Common errors.

"Spotify is signed with a different key"

The installed Spotify was not signed by your Manager's key. Import the key it was signed with, or uninstall it (this removes downloads) and install again.

"That file isn't the Spotify APKM Spatch is made for"

The file is a different version or was modified. Get Spotify 9.2.0.2053 (version code 148387875) again and pick the APKM, not an APK or XAPK.

The quick update did not take

Tap Install again: the Manager falls back to reinstalling every APK.

Could not reach GitHub

The Manager needs a connection to find and download patches. Check your network and tap Check for updates.
