# Bundled fonts

Unmodified official releases, redistributed with the app under the SIL Open Font License 1.1, whose
full text ships beside them in `licenses/` and is shown in Settings > Typography > Font licenses.
Nothing here is renamed inside the font, subset or sold on its own, so the Reserved Font Name clauses
are not triggered.

| Family | Source | License file |
| --- | --- | --- |
| Roboto | github.com/google/fonts `ofl/roboto/Roboto[wdth,wght].ttf` | OFL-Roboto.txt |
| Noto Sans | github.com/google/fonts `ofl/notosans/NotoSans[wdth,wght].ttf` | OFL-NotoSans.txt |
| Atkinson Hyperlegible | github.com/google/fonts `ofl/atkinsonhyperlegible` Regular and Bold | OFL-Atkinson.txt |
| Monaspace Neon, Argon, Xenon, Radon, Krypton | github.com/githubnext/monaspace v1.400 `monaspace-variable-v1.400.zip` | OFL-Monaspace.txt |

Filenames are ours (the shipped asset paths); file contents are byte-identical to the sources.
