FAQ

Questions, answered

Is Spatch safe?

Spatch is open source: everything it changes is in the repository, and the manager checks every file against its SHA-256. It needs no account and sends nothing anywhere. It is still a modified app, so it can't come with Spotify's guarantees.

Can my account get banned?

Modified clients are against Spotify's terms. Spatch only changes how the app looks and doesn't unlock anything, so the risk is low, but it isn't zero. Use it at your own risk.

Does Spatch remove ads or unlock Premium?

No. Spatch is cosmetic by design. It doesn't skip, block or hide ads, and it doesn't unlock Premium features. On free accounts it only makes sure its own artwork doesn't fight with Spotify's ad cards.

Why do I need a specific Spotify version?

Spatch edits Spotify's own code in exact places. Each Spotify release moves those places, so every version needs its own patches. Spatch refuses anything it wasn't built for instead of patching blindly.

Why does Spotify have to be uninstalled the first time?

Android only updates an app with one signed by the same key. Spatch is signed with your phone's key, not Spotify's, so the original has to go first. After that every update installs in place.

What happens if I lose my key?

You'd have to uninstall Spatch to install a build signed by a new key, losing downloads. Export the key from the manager and keep it safe.

Does Spatch work on free accounts?

Yes. Free accounts can also hide the Premium tab.

Can I go back to normal Spotify?

Uninstall Spatch and install Spotify from the Play Store.

Where are Spatch's settings?

Open Spotify's side panel (your profile picture) and choose Spatch.

Who makes Spatch?

Spatch is an independent, unofficial project. It is not affiliated with or endorsed by Spotify AB.
