Changelog

What's new.

Recent highlights for Spatch patches and Spatch Manager. Full release notes and APK downloads live on GitHub.

Patches

Shared cover flight, miniature theme previews & heart bursts

Added shared-element cover flight transitions into playlist and album pages, miniature app-window palette cards in Appearance, an animated overshoot pill indicator on landscape Lyrics | Up next tabs, and a confetti burst of hearts when saving the current song.

Patches

Contour visualizer mode, delta-drag EQ & greeting badge

Added a fluid radial Contour visualizer option alongside Bars and Ring, smooth relative delta-drag gestures on the equalizer curve, and an expressive time-of-day shape badge beside the Home greeting.

Patches

Bass cover pulse, header stickers & landscape Home/Library

Added subtle bass-reactive cover breathing inside the visualizer ring, dual-colour ambient cover glows, deterministic background stickers behind playlist/album headers, a floating seek-time pill with track-change scrub guard, four-column landscape Library grids, and side-by-side landscape Home quick cards.

Patches

Direct visualizer, two-tone cover palettes & Gaussian EQ

Read audio directly from Spotify's output stream without microphone permissions, extract distinct primary and secondary accents from multi-colour album covers, and shape sound on a continuous Gaussian-summed equalizer curve with a live dB badge.

Patches

Landscape Up next tabs, idle-fade picker & rich Sleep timer

Switch between synced lyrics and the interactive Up next queue beside the cover in landscape, pick individually which player elements fade when idle, restart cleanly on Previous at 0:00, and adjust an active sleep timer by ±5 minutes with live countdown.

Patches

Widget clipping, softer cover glow & zero idle frames

Polished widget corner clipping and text readability shadows, smoothed circular visualizer proportions across landscape screens and removed abrupt glow rings, and eliminated idle render wakeups when playback is paused.

Patches

Time-synced lyrics screen & player lyric strip

Added a dedicated time-synced lyrics screen where the sung line glows and the column glides smoothly to keep it centred—tap any line to jump straight there. You can also turn on an optional three-line lyric strip in the player, over a smooth cover blur backdrop, with every piece of the player optional in settings.

Patches

Adaptive home-screen widgets

Widgets now feature a square cover that adapts to the size you give them, plus a stacked layout for tall widgets.

Patches

Spotify 9.2.0.2053 target & SHA-256 verification

Built for Spotify for Android 9.2.0.2053 (version code 148387875) as an APKM bundle. Every input APKM, split APK, and patched entry is checked against its exact SHA-256.

Manager

Clones, nightly patches & live build progress

Install a second Spotify clone beside the first with its own package name, app name, and adaptive launcher icon. Opt into nightly patches with live build progress, self-updates, and one-tap base.apk updates (silent on Android 12+).
