Changelog

What's new

Recent highlights for Spatch patches and Spatch Manager. Full release notes and APK downloads live on GitHub.

Patches

Time-synced lyrics screen & player lyric line

Added a dedicated time-synced lyrics screen where the currently sung line glows and the column glides smoothly to keep it centred—tap any line to jump straight there. You can also turn on an optional one-line lyric in the player.

Patches

Spotify 9.2.0.2053 target & SHA-256 verification

Built for Spotify for Android 9.2.0.2053 (version code 148387875) as an APKM bundle. Every input APKM, split APK, and patched entry is checked against its exact SHA-256.

Manager

Clones, nightly patches & live build progress

Install a second Spotify clone beside the first with its own package name, app name, and adaptive launcher icon. Opt into nightly patches with live build progress, self-updates, and one-tap base.apk updates (silent on Android 12+).
